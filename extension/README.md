# Sentinel — Chrome & Browser Authoring Companion (Manifest V3)

> **Round 3 Improvement 1:** Real-Time Inline Authoring Companion.  
> Embeds Sentinel's dual-engine reviewer directly into authoring environments (Google Docs, Notion, web textareas, CMS inputs).

---

## 3-Step Sideloading Instructions for Judges:

1. Open **Google Chrome** (or Edge / Brave) and navigate to `chrome://extensions`.
2. Toggle on **"Developer mode"** in the top-right corner.
3. Click the **"Load unpacked"** button in the top-left corner, and select this folder (`d:\Codestar30\extension`).

---

## Features
* **Live Synchronous Checking**: Queries Sentinel's `/api/companion/check` endpoint with sub-second response times.
* **Inline Floating Pill**: Injects a sleek floating compliance score badge on any active web input or Google Docs tab.
* **Grounded Clause Citations**: Displays exact rule/fact IDs and intent-preserving fixes without opening a full dashboard.
* **Jurisdiction Switcher**: Instantly switch between Global, India (ASCI), US (FTC), and EU (Green Claims).
